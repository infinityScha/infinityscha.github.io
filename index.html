How I work

1 · Model

I start from the physics or the statistics and write it down as an energy, a likelihood or a simulation, with the assumptions explicit. Then I test it against what actually happened.

2 · Solve

I solve it with optimisation, Monte Carlo, finite elements or molecular dynamics, on a laptop or an HPC cluster. I profile first, then compile the hot loop.

3 · Ship

When a model is worth using, I package it: clean modules, tests, a written spec, and a running tool or service.
